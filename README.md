# E-Mitra - Android Note-Taking Application

## Overview
E-Mitra is an Android note-taking application developed using Java in Android Studio. It allows users to create, edit, and manage notes with a simple and user-friendly interface.

## Features
- Create Notes
- Edit Notes
- Delete Notes
- View Notes
- User Authentication
- Firebase Integration
- SQLite Database

## Tech Stack
- Java
- Android Studio
- Firebase
- SQLite
- XML
